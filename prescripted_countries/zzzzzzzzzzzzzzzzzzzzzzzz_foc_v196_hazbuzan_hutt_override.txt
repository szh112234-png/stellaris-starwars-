# V196 - a Hutt-species version of the Hazbuzan Syndicate megacorp design.
#
# V232 FIX: the original V196 comment assumed that a later filename would make
# this block *override* Stellaris' 94_megacorp_prescripted_countries.txt entry
# of the same key. That is not how prescripted_countries works in 4.x - entries
# sharing a key are MERGED, and repeated list fields (trait / ethic / civic /
# ruler trait) are appended rather than replaced. The result was one design
# carrying ten species traits, four ethics, four civics and two ruler traits, so
# the game rejected it outright:
#   "Hiding invalid prescripted empire design 'hazbuzan':
#    选择的思潮超过了点数阈值 / 选择的国民理念超过了点数阈值 /
#    复制特质有机体 ... 你为你的物种选择了太多的特质"
# The vanilla Hazbuzan design was destroyed along with it, so BOTH designs
# disappeared from the empire picker.
#
# The key is now unique, which restores the vanilla design and makes this one a
# valid standalone Hutt option. Everything below is unchanged from V196.
