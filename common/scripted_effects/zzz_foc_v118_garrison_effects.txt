# FOC V118: hull selection for the three story Executor guard groups.
#
# An AI Galactic Empire gets the sublight garrison hulls: normal Imperial
# warships with no FTL drive, so Executor, Lusankya and Punisher manoeuvre
# freely inside Endor, Coruscant and Jakku and cannot leave them. No AI order
# and no jump drive can pull them out, and nothing has to teleport them back.
# A human Empire keeps the ordinary FTL-capable hulls, because confining the
# player's three flagships to one system would be a punishment, not a feature.
#
# Called from fleet scope inside create_fleet, after set_owner. The owner is
# read from event_target:foc_republic_origin_executor_reward_owner, which every
# caller saves before spawning.

# V118b: written out once per flagship instead of one $SHIPNAME$ / $FLAG$
# effect called three times. The parameterised version did not survive
# substitution - a quoted argument left a stray $ in the create_ship block and
# the game logged "Unexpected token" for all six branches, so no flagship would
# have spawned at all. Three literal copies cannot fail that way.
